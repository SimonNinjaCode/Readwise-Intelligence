# Readwise Intelligence

Automatiskt genererade rapporter baserade på material i Readwise Reader.

## Rapporter

- `reports/cybersecurity/` – veckovisa cybersäkerhetsrapporter
- `reports/threat-intelligence/` – veckovisa threat intelligence-rapporter
- `reports/generative-ai/` – veckovisa rapporter om generativ AI
- `reports/notebooklm-digest/` – NotebookLM-digests baserade på veckorapporterna
